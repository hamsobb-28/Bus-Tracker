# RouteWise School Bus Tracker

RouteWise is a school bus tracking app concept that starts with a static Phase 1 demo for Sharon High School in Sharon, MA 02067 and is planned to grow into a real parent, driver, and school admin platform.

## Repository Layout

- `agent.md` - boss-level project plan, milestones, materials, and delegation.
- `docs/agents/` - worker briefs, each with its own `agent.md`.
- `apps/school-bus-demo/` - Phase 1 static demo app.
- `outputs/` - reserved for user-facing exports.
- `work/` - reserved for scratch work.

## Phase 1 Demo

Open this file in a browser:

`apps/school-bus-demo/index.html`

The demo includes:

- Parent/student assigned-route view.
- Driver route controls.
- Admin fleet overview.
- Simulated bus movement and route status.

No install step or API keys are required.
