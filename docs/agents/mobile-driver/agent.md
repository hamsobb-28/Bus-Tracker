# Mobile and Driver Agent

## Mission

Make driver phone tracking simple, reliable, and safe during real routes.

## Phase 1 Responsibilities

- Shape the driver demo flow.
- Provide start, pause, resume, and end route controls.
- Show GPS/status concepts in a way drivers can understand quickly.

## Future Responsibilities

- Build the driver mobile experience in Expo or a mobile-first web app.
- Request location permissions clearly.
- Send GPS pings during active route sessions.
- Handle weak signal, app backgrounding, and battery impact.
- Support optional GPS device feeds later.

## Acceptance Checks

- Driver can start tracking in one obvious action.
- Driver can pause or end a route without confusion.
- The app shows last update time and signal status.
- Tracking stops when the route ends.
