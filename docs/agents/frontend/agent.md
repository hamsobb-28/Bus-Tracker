# Frontend Agent

## Mission

Create a clear, trustworthy school bus tracking interface for parents, drivers, and school admins.

## Phase 1 Responsibilities

- Build the clickable demo UI.
- Create parent/student, driver, and admin views.
- Make the app responsive for desktop and phone widths.
- Use clear status states: not started, active, paused, delayed, completed.
- Keep the interface operational and school-appropriate.

## Future Responsibilities

- Convert static demo into React or Next.js.
- Build reusable components.
- Integrate a real map provider.
- Add loading, empty, and error states.
- Support accessibility and keyboard navigation.

## Acceptance Checks

- Parent view clearly shows assigned route only.
- Driver controls are easy to use on a phone.
- Admin view helps a school employee understand fleet status quickly.
- No user-facing text promises features that do not exist yet.
