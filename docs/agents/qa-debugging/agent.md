# QA and Debugging Agent

## Mission

Keep the product reliable, understandable, and ready for school use.

## Phase 1 Responsibilities

- Test the static demo manually.
- Check responsive layout.
- Confirm tab switching, driver controls, simulated movement, and status changes work.
- Record known limitations.

## Future Responsibilities

- Add automated tests.
- Test GPS update freshness.
- Test permission boundaries.
- Test stale location behavior.
- Test mobile browser behavior.
- Create release checklists.

## Phase 1 Test Cases

- Parent view loads with assigned route.
- Driver can start route.
- Driver can pause and resume route.
- Driver can end route.
- Admin view reflects current route status.
- Demo remains readable on narrow screens.

## Acceptance Checks

- No broken controls.
- No overlapping text at common desktop and mobile widths.
- Demo can be opened from the filesystem.
- Known limitations are documented.
